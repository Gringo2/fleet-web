# Localization (i18n) Guide

Traccar is translated into over 60 languages. This guide explains how to add or update translations for both the frontend and backend.

## 1. Frontend (`traccar-web`)

The frontend uses standard JSON files for localization.
- **Location**: `src/resources/l10n/`
- **Format**: `[language_code].json` (e.g., `en.json`, `es.json`)

### Updating Translations
1.  Open the JSON file for your language.
2.  Add or modify the key-value pairs.
3.  The frontend automatically detects the browser language and loads the corresponding file.

### Adding a New Language
1.  Copy `en.json` to your new language code (e.g., `fr_CA.json`).
2.  Translate the values.
3.  Register the new language in the UI settings (usually handled dynamically based on the directory content).

## 2. Backend (`traccar`)

The backend uses localized strings for notification templates and system messages.

### Notification Templates
- **Location**: `templates/mail/[language]/`
- **Format**: `.vm` (Velocity) files.
- **Fallthrough**: If a template is missing in a specific language, Traccar falls back to the default `en` template.

### Logged Attributes
Some attribute names (like "ignition" or "alarm") are translated on the frontend based on the keys received from the backend. Ensure that custom attributes in the backend follow the naming convention used in the `en.json` keys to benefit from automatic translation.

## 3. Contributing Translations

Translations are managed by the community.
- **Official Portal**: Use [Transifex](https://www.transifex.com/traccar/traccar/) to contribute translations without editing code. Changes from Transifex are periodically synced into the repository.
